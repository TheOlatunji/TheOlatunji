### 1. Digital Invoice Generator
A professional, localized billing and invoice management web application built to streamline operations for SMBs, freelancers, and creative agencies.
* **Tech Stack:** Next.js 15 (App Router), TypeScript, Supabase (Auth, Postgres, Storage), Tailwind CSS 4, `@react-pdf/renderer`

### 2. Autonomous Grant & Fellowship AI Agent
An end-to-end intelligent pipeline designed to discover, evaluate, and digest market opportunities matching specific professional vectors.
* **Tech Stack:** Python, Anthropic (Claude API), Tavily Search API, Supabase, Resend API, GitHub Actions
* **Core Engineering:**
    * **Automated Discovery:** Leverages Tavily to scrape real-time global grant and fellowship datasets.
    * **LLM Filtering:** Uses Claude to contextually evaluate discoveries against strict alignment matrices, mitigating noise.
    * **Serverless Execution:** Orchestrated entirely via GitHub Actions to execute state storage in Supabase and dispatch a weekly digest via Resend every Monday morning automatically.

### 4. Operations & Revenue Tracker
A centralized internal operations tracker custom-built for a fast-paced writing and content-solution agency.
* **Tech Stack:** Google Apps Script, Google Forms, Google Calendar, Google Sheets API
* **Core Engineering:**
